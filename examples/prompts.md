# Prompt Examples

The prompts below can be copied directly into Codex.

## Just Plan the Illustrations

```text
Use $ian-xiaohei-illustrations Don't generate images yet.
Please analyze where this article deserves illustrations and output a shot list of about 5 images.
For each image, specify:
- Which paragraph it follows
- Image theme
- Core meaning
- Structure type
- What Xiaohei is doing in the image
- Suggested elements
- Suggested annotation words

<paste article>
```

## Article Inline Illustrations

```text
Use $ian-xiaohei-illustrations Generate 4 Xiaohei absurd inline illustrations for this article.
Requirements: 16:9 landscape, pure white background, black hand-drawn line art, sparse red/orange/blue handwritten annotations.
Each image tells only one core structure — no PPT infographics, no cute cartoons.

<paste article>
```

## Long Article Illustration Strategy

```text
Use $ian-xiaohei-illustrations Make an illustration strategy for this long article.
Don't illustrate evenly; only pick cognitive anchors: core judgments, input-output loops, before/after, common pitfalls, handoff paths.
Default 6-8 images. Output the shot list first; don't generate images yet.

<paste article>
```

## Single Concept, One Image

```text
Use $ian-xiaohei-illustrations Generate one 16:9 inline illustration for this concept:

Trust is not shouted — it's built piece by piece with evidence.

The image should be absurd yet crisp, and Xiaohei must perform the core action.
At most 5 short annotations.
```

## Edit an Existing Image

```text
Use $ian-xiaohei-illustrations Help me edit this image — remove the "Flowchart" title in the top-left corner, keeping everything else.
```

## Regenerate with More Absurdity

```text
Use $ian-xiaohei-illustrations Regenerate this illustration. Keep the same core meaning and layout, but make Xiaohei more central to the action. Make it weirder but still readable.
```
