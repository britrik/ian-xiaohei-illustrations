# Composition Patterns & Originality Rules

## Basic Structure Types

Choose one structure — don't mix too many.

### Workflow

Suitable for: Input -> Process -> Output, content production, AI workflows, automation chains.

Drawing: Input on the left, Xiaohei or a weird machine in the middle, output on the right, orange arrows expressing main flow direction.

### System Detail

Suitable for: Information sources, filters, databases, renderers, agent system components.

Drawing: Only 3-5 core modules, Xiaohei participates in one key action.

### Before/After

Suitable for: Chaos/orderly, manual/automatic, scattered/ gathered, anxious/stable.

Drawing: Left = chaos, right = stable, orange arrow in the middle. Characters can be more exaggerated.

### Character State

Suitable for: User pain points, creator state, too many tools, information anxiety, stuck to running.

Drawing: 2-4 small states, each state with a short annotation.

### Conceptual Metaphor

Suitable for: Content factory, information warehouse, brain black box, workflow machine, auto daily report.

Drawing: One big weird object or machine, few inputs, one output. Needs to be memorable.

### Method Layers

Suitable for: Methodology frameworks, system layers, capability stacks, content system layers.

Drawing: Layered boxes, not formal pyramids; Xiaohei bricks or builds nearby.

### Map Route

Suitable for: Idea to launch, user path, content handoff path, learning route.

Drawing: One curved path, few nodes, Xiaohei pulling wire or walking.

### Mini Comic Panels

Suitable for: Failure to success, real process,吐槽, before/after changes.

Drawing: 2-4 small scenes, each panel expressing one action.

## Original Metaphor Generation Method

Reinvent metaphors fresh each time from the current article — never copy old images.

### Three Steps

1. Replace abstract concepts with a physical action: stuck, leaked, got heavier, sorted, settled, fermented, opened door, folded, unpacked, backflow.
2. Replace system structure with a low-tech object: broken machine, cardboard box, drawer, water pipe, mailbox, weird dial, scale, well, ladder, strange workstation.
3. Have Xiaohei perform the action: not standing beside, but stuck in the machine, pulling wrong wire, guarding door, carrying, patching, weighing, holding ladder, recording, stuffing things into a weird device.

### Available Object Pool

- Cardboard box, drawer, old machine, funnel, scale, mailbox, door, well, ladder, water pipe, ball of yarn, gate, turntable, black box, puncher, noodle press, clothesline, weird workstation.
- Only pick 1-2 when using; don't pile up.

### Xiaohei Action Pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, dismantle, mark, recycle.
- Actions should serve the core meaning; don't be weird for weirdness's sake.

## Anti-Recycling Rules

Do not open or copy `assets/examples/` by default. These images are only for style calibration: line density, white space, color restraint, Xiaohei temperament.

Unless the user explicitly says "copy this / recreate this composition / modify this case", do not directly reuse these old compositions:

- Conveyor belt two breakpoints
- Xiaohei pulling judgment lever inside content machine
- Xiaohei becoming funnel sorting traffic/trust/conversion
- Xiaohei slicing material fish
- Xiaohei leading handoff path
- Xiaohei pulling three-layer information sources
- Three Xiaobeis holding megaphone / bridging / opening door
- Xiaohei stamping phrase toolbox
- Xiaohei holding sign watching common pit path

Same-topic images also need new metaphors. For example, "handoff path" doesn't have to be a route — can be Xiaohei connecting a content tail to a door handle; "one fish many uses" doesn't have to be a fish — can be Xiaohei pressing one paper ball into several shapes.
